## Temperature Conversion Program

A simple Python program that converts temperature values between:
Celsius (°C)
Fahrenheit (°F)
Kelvin (K)

## Project Description

This program allows users to:
Enter a temperature value
Choose the original unit (C/F/K)
Automatically convert the temperature to the other two units
Display the converted results

## Technologies Used
Python 3

## Features

User-friendly input system

Converts between all three temperature scales

Error handling for invalid inputs

Clean and simple code structure
